# ربات تریدینگ کریپتو (Crypto Trading Bot)

این ربات ساده و قدرتمند برای ترید کریپتو ساخته شده. از صرافی‌های Bitunix یا LBank داده می‌گیره، جدول قیمت‌ها رو نشون می‌ده، با هوش مصنوعی (Groq/Llama) تحلیل می‌کنه، و آلارم به تلگرام می‌فرسته. ایده‌آل برای ایرانی‌ها (بدون تحریم!).

## ویژگی‌ها
- **جدول داده (Data Grid)**: قیمت، حجم، تغییر ۲۴ ساعته، high/low.
- **هوش مصنوعی**: تحلیل تصمیم (بخر/بفروش/نگه‌دار) با استاپ و تارگت.
- **آلارم تلگرام**: وقتی شرطی (مثل BTC > 100k) برقرار بشه.
- **پشتیبانی صرافی**: Bitunix (API key داری) یا LBank.
- **رایگان**: فقط Groq API key بگیر (groq.com — ۱۰۰ درخواست رایگان در دقیقه).

## راه‌اندازی قدم به قدم (۱۰ دقیقه)
### ۱. نصب Python و کتابخونه‌ها
- Python 3.8+ نصب کن.
- `pip install -r requirements.txt`

### ۲. تنظیمات
- فایل `.env.example` رو به `.env` کپی کن و پر کن:
  - API key و secret Bitunix/LBank.
  - GROQ_API_KEY از groq.com.
  - TELEGRAM_TOKEN و CHAT_ID از BotFather (تلگرام بات بساز).

### ۳. اجرا
- تو config.py، EXCHANGE رو 'bitunix' یا 'lbank' ست کن.
- `python main.py` بزن.
- خروجی: جدول + تحلیل AI + آلارم اگر لازم.
